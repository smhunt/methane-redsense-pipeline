SONAMI · Phase 4 — Visualize & Export

TDLAS × Pix4D methane correlation report

What python -m sonami.cli visualize renders after Phases 1–3: the interpolated methane surface with high-agreement zones, global spatial autocorrelation, per-band point-to-pixel correlation, and the best-band scatter — for the W12A landfill survey.

◆ SYNTHETIC

Every number on this page is fabricated demo data, not a real W12A result. It exists only to show the layout and the kinds of statistics the pipeline produces. The map, Moran's I, the band table and the scatter are all computed in your browser from one seeded synthetic methane field, so they are internally consistent with each other — but they describe nothing about the actual site.

In particular, the "NDRE tracks methane strongest" story below is an invented construct, not evidence about landfill vegetation stress. Real figures appear only after config/sonami.yaml is filled with the actual TDLAS export and Pix4D orthomosaic and the pipeline is run on that data.

Reminder: this page is a synthetic mock-up for layout review only. The live run writes an interactive correlation_map.html over the real orthomosaic, a correlation_points.geojson for stakeholders, and scatter_<band>.png — populated with measured values, which may look nothing like the demo above.
