Annotation key

marker → component → source
1
Masthead
Eyebrow, H1, one-line description. Names the phase and the site.
2
Synthetic banner
Amber-in-real, pinned above every chart. Non-negotiable — states all values are fabricated demo data.
3
Correlation map
IDW methane raster + flight-line points + agreement ring, with ramp legend. → visualize.correlation_map
4
Moran's I card
Big observed I, clustered/dispersed pill, expected/p/weights/n list. → correlation.morans_i
5
Per-band table
Pearson r, Spearman ρ, R², p, n per band; best row flagged. → correlation.correlate_bands
6
Best-band scatter
Methane vs top band + OLS fit, with r/R² stat list. → visualize.scatter_plot
7
Footer
Real run command (python -m sonami.cli run) + synthetic reminder.
